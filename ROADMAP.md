# Config Studio Roadmap & Planned Plugins 🗺️

План развития экосистемы **Config Studio** и официальных плагинов.

---

## 📋 Запланированные плагины и функции

### 1. 🐳 Плагин: Docker & Compose Manager (`config-studio-docker`)
Полноценное управление контейнерами и сценариями Docker Compose прямо из интерфейса редактора.

#### Ключевой функционал:
- **Контекстные кнопки в панели инструментов** (активируются при открытии `docker-compose.yml`, `compose.yaml`, `Dockerfile`):
  - 🚀 **Compose Up (`-d`)** — фоновый запуск стека сервисов.
  - ⬇️ **Compose Down** — корректная остановка и удаление контейнеров и сетей.
  - 🔄 **Compose Pull & Restart** — обновление образов и перезапуск контейнеров в 1 клик.
  - 📋 **Live Logs Viewer** — стриминг логов сервисов в нижнюю панель (Bottom Panel) в реальном времени с поддержкой паузы и фильтрации.
  - 🔍 **Status & Containers Dashboard** (`docker compose ps` / `docker ps`) — интерактивный список контейнеров со статусами (Up/Exited), портами и кнопками перезапуска каждого сервиса по отдельности.
- **Поддержка синтаксиса и AST**:
  - Сниппеты для директив Compose (`services`, `volumes`, `networks`, `environment`, `healthcheck`, `deploy`).
  - Outline Provider для быстрого перехода к отдельным сервисам в дереве структуры документа.
- **Требуемые разрешения**: `ui.panels`, `terminal.exec`.

### 2. 📡 Плагин: Remote Server Agent — Broadcast & Multicast с функцией Approve
Расширение для плагина [`config-studio-remote-agent`](https://github.com/EdvardBaldanov/config-studio-remote-agent) для кластерного управления.

#### Ключевой функционал:
- **Тегирование и группы серверов**: разделение парка серверов по тегам (`prod`, `staging`, `edge`, `backend`).
- **Синхронная рассылка (Multicast / Broadcast)**: отправка отредактированного конфига сразу на несколько или все подключенные серверы.
- **Интерактивный экран подтверждения (Approve Modal)**:
  - Визуальный просмотр Diff (изменений).
  - Pre-flight детекция дрифта (проверка хешей и предупреждение, если файл на сервере был отредактирован локально).
  - Выборочное включение/исключение серверов чекбоксами.
  - Кнопка **«Approve & Deploy»**.
- **Отказоустойчивость**: автосоздание `.bak` копий на целевых узлах и детальный отчет доставки (Success/Failed).

### 3. 💻 Скрываемая нижняя панель для CLI и инструментов (Collapsible Bottom Dock)
Выделенная нижняя док-панель (Bottom Console / CLI Panel) для размещения встроенных терминалов, потоков вывода команд и консольных инструментов.

#### Ключевой функционал:
- **Универсальный Bottom Dock**:
  - Поддержка переключения видимости через API плагинов: `window.ConfigStudio.toggleBottomPanel({ id, title, render })`.
  - Глобальный хоткей для быстрого сворачивания / разворачивания (по аналогии с VS Code / JetBrains: `Ctrl+\`` или `Ctrl+J`).
  - Кнопка быстрого доступа в панели состояния (Status Bar) или тулбаре редактора с индикатором активных сессий.
- **Интерактивные возможности**:
  - Многовкладочность в нижней панели (например, вкладка `Terminal`, вкладка `Docker Compose Logs`, `Output`).
  - Плавный ресайз высоты (drag-to-resize сплиттером) и пресеты высоты (минимизировано / 240px / 420px / полноэкранный режим).
  - Сохранение состояния (открыта/закрыта, высота) в пользовательских настройках (`settings.json`).
- **Целевые сценарии применения**:
  - 🖥️ **CLI / Terminal плагин** (`config-studio-terminal` / `config-studio-cli` на базе xterm.js): доступ к локальному шеллу (PowerShell, Bash, zsh) или удаленной SSH-консоли серверов.
  - 🐳 **Стриминг логов**: вывод stdout/stderr контейнеров `docker compose logs -f`.
  - ⚡ **Task Runner / Build Output**: отображение вывода линтеров, сборщиков и скриптов валидации.
- **Требуемые разрешения**: `ui.panels`, `terminal.exec`.

### 4. 📦 Динамический каталог плагинов (Official / Community) и переносимые источники
Переход от жестко зашитого списка плагинов в коде к динамическому каталогу с разделением на официальные и пользовательские плагины, а также поддержка переносимости между машинами.

#### Ключевой функционал:
- **Разделение индекса (`registry.json`)**:
  - Четкое разделение каталога на две секции:
    - `official`: плагины, поддерживаемые и верифицированные командой проекта (`web-devkit`, `remote-agent`, `docker`, `terminal`).
    - `community`: проверенные плагины от сообщества с указанием автора, лицензии и плашкой *«Community»*.
  - В интерфейсе настроек: удобные фильтры / вкладки *«Официальные»* и *«Сообщество»*.
- **Портативность доверенных источников (Seamless Migration)**:
  - Хранение доверенных репозиториев в отдельном файловом формате `plugins/sources.json` (или `settings.json`) — легко скопировать на любой сервер или рабочую станцию.
  - Функция **«Экспорт / Импорт профиля в 1 клик»**: создание файла `config-studio-profile.json` (список подключенных источников, активных плагинов и настроек темы) для мгновенного развертывания окружения на новой машине.
- **Динамическое обнаружение (Discovery по маске GitHub)**:
  - Автоматический опрос GitHub API доверенных организаций / пользователей по маске `config-studio-*` или топику `config-studio-plugin`.
  - При появлении нового репозитория с манифестом `plugin.json` плагин автоматически появляется в каталоге без пересборки бинарника.
- **Безопасность**:
  - Предупреждения при установке непроверенных плагинов из сторонних источников.
  - Проверка совместимости версии редактора (`minAppVersion`).

### 5. 🛡️ Ядро: Защита и валидация конфигураций («Редактор конфигов, а не IDE»)
Сохранение философии легковесного и надежного ядра. Базовая версия Config Studio из коробки идеально поддерживает исключительно форматы конфигураций: **YAML, YML, TOML, JSON, JSONC, INI, CONF, CFG, .ENV, PROPERTIES**.

#### Ключевой функционал:
- **Глубокая валидация структуры (Structure Guard)**:
  - Защита от фатальных сбоев сервисов на продакшене из-за синтаксических ошибок в конфигах.
  - **YAML**: строгий контроль отступов (отлов табуляций вместо пробелов, сбитой вложенности), обнаружение дублирующихся ключей, незакрытых кавычек.
  - **JSON / JSONC**: строгий синтаксический чекер, детекция незакрытых фигурных/квадратных скобок, лишних запятых.
  - **TOML / INI**: проверка корректности объявлений секций `[section]` и пар `key = value`.
  - **.ENV**: обнаружение недопустимых пробелов вокруг `=`, экранирования спецсимволов.
- **Защита при сохранении (Pre-save Guard)**:
  - Если в файле обнаружены критические ошибки структуры, при нажатии `Ctrl+S` всплывает предупреждающий диалог:  
    *«Внимание: в структуре конфига обнаружены синтаксические ошибки, которые могут нарушить работу сервиса. Сохранить принудительно?»*.
- **Словари и автокомплит для конфигов**:
  - Подсказки булевых типов (`true`/`false`), номеров портов, путей файловой системы, синтаксиса переменных окружения (`${VAR_NAME}`).
  - Подсказка стандартных директив популярных серверных конфигураций (nginx, systemd, docker-compose).
- **Минимальные базовые шаблоны (New File Templates)**:
  - Встроенные стартовые шаблоны при создании новых файлов:
    - Чистый `.env` (типовая структура: `APP_ENV`, `PORT`, `DB_HOST`, `SECRET_KEY`).
    - Базовый `config.yaml` / `config.toml` (секции `server`, `database`, `logging`).
    - Минимальный `nginx.conf` (`server { listen 80; ... }`).

### 6. 🌐 Веб-разработка: расширение плагина `config-studio-web-devkit`
Все веб-форматы и языки программирования (**HTML, PHP, JS, CSS**) развиваются **строго внутри плагина**, не перегружая базовое ядро Config Studio.

#### Ключевой функционал:
- 🏷️ **Отображение и инспекция секции `<head>` (Head & Metadata Inspector)**:
  - **Исправление структуры и Quick Jump**: перестать отбрасывать `<head>` при построении дерева тегов; разделять дерево на четкие узлы `<head>` и `<body>`.
  - Быстрый переход в Quick Jump к ключевым элементам `<head>`: `<title>`, метатегам, фавиконке, подключенным таблицам стилей (`<link rel="stylesheet">`) и скриптам (`<script>`).
  - **В панели Live Preview**: отображение реального заголовка вкладки и плашки-инспектора заголовков (список загруженных CSS/JS ресурсов страницы и статус их доступности).
- **Словари и автодополнение**:
  - Полный словарь тегов и атрибутов HTML5.
  - Словарь встроенных функций и суперглобальных массивов PHP (`$_POST`, `$_GET`, `pdo`, `json_encode` и др.).
- **Проверка структуры и синтаксиса**:
  - Валидация DOM-структуры HTML (контроль закрытия парных тегов, корректности таблиц и форм).
  - Базовый синтаксический чекер PHP для исключения критических ошибок (Parse Error / Fatal Error).
- **Минимальные стартовые шаблоны**:
  - Стандартный `index.html` (валидный HTML5 Boilerplate с метатегами viewport, title и структурой body).
  - Базовый `index.php` (минимальный скрипт/API контроллер).

### 7. 📁 Плагин: Расширенные операции проводника файлов (`config-studio-explorer-plus`)
Продвинутое управление файлами и конфигурациями в левом проводнике (File Explorer) без необходимости переключаться в сторонний файловый менеджер.

#### Ключевой функционал:
- 📋 **Копирование, вырезание и вставка (Copy / Cut / Paste)**:
  - Поддержка стандартных горячих клавиш (`Ctrl+C`, `Ctrl+X`, `Ctrl+V`) при фокусе на проводнике файлов.
  - Вставка скопированного файла в текущую или любую выбранную директорию с авторазрешением коллизий имен.
- 📑 **Дублирование в 1 клик (Duplicate)**:
  - Мгновенное клонирование файла с генерацией суффикса копии (например, `config.yaml` -> `config_copy.yaml` или `config (1).yaml`).
  - Удобно для быстрого тестирования альтернативных конфигураций сервиса.
- 🛡️ **Быстрое создание снимка (.bak / Quick Backup)**:
  - Кнопка создания резервной копии перед опасными правками с временной меткой: `nginx.conf.bak` или `app.2026-10-19.bak`.
- 🖱️ **Контекстное меню по правому клику (Context Menu Extension Slot)**:
  - Выпадающее меню по клику правой кнопкой мыши на файле или папке:
    - *Открыть / Открыть рядом (Split)*
    - *Копировать / Вырезать / Вставить*
    - *Дублировать*
    - *Создать быстрый бэкап (.bak)*
    - *Копировать путь (абсолютный / относительный)*
    - *Свойства и история ревизий файла*
    - *Переименовать / Удалить*
  - **Слот для других плагинов**: возможность плагинам регистрировать свои контекстные действия (например, плагин `config-studio-docker` добавляет пункт *«Compose Up»* при правом клике на `docker-compose.yml`).
- 🗂️ **Групповые операции (Multi-select)**:
  - Выделение группы файлов через `Shift` / `Ctrl` для массового копирования, перемещения или удаления.
- **Требуемые разрешения**: `ui.contextMenu`, `fs.operations`.

### 8. 🔨 Плагин: Запуск сценариев сборки Makefile / Task Runner (`config-studio-makefile`)
Автоматизация рутины сборки и DevOps-задач прямо из редактора со строгой привязкой к файлам сценариев.

#### Ключевой функционал:
- 🎯 **Строгая ассоциация по маске (`fileMatches`)**:
  - `fileMatches: ["Makefile", "makefile", "GNUmakefile", "*.mk"]`
  - Плагин и его кнопки запуска активируются **только** при открытии настоящего Makefile, исключая ложные срабатывания на обычных конфигах.
- 🔍 **Автопарсинг целей (Targets & Docstrings)**:
  - Извлечение всех целей (`build`, `test`, `run`, `deploy`, `lint`, `clean`) и комментариев-описаний к ним (например, `## Build production binary`).
- 🚀 **Быстрый запуск из интерфейса**:
  - Кнопка в тулбаре редактора: `[ ▶ Run: build ▾ ]` с выпадающим списком доступных целей.
  - Дерево целей в структуре документа (Outline) — клик запускает выполнение выбранной цели.
- 📋 **Стриминг в нижнюю панель (Bottom Dock)**:
  - Потоковый вывод stdout/stderr в реальном времени с подсветкой синтаксиса, статусом завершения (SUCCESS / FAILED), временем работы и кодом выхода.
- **Требуемые разрешения**: `ui.toolbar`, `ui.panels`, `terminal.exec`.

### 9. 🤖 Плагин: Сервер Model Context Protocol (`config-studio-mcp`)
Превращение Config Studio в официальный MCP-сервер для безопасного подключения внешних ИИ-ассистентов (Claude Desktop, Cursor, Antigravity, локальные LLM).

#### Ключевой функционал:
- 🛠️ **Инструменты для ИИ-агентов (MCP Tools)**:
  - `read_config(path)`: чтение конфига с извлечением структуры AST.
  - `validate_structure(content, format)`: валидация синтаксиса встроенным ядром Config Studio (YAML, JSON, TOML, ENV) перед сохранением.
  - `diff_config(path, new_content)`: генерация безопасного diff изменений.
  - `deploy_remote(server_id, path)`: доставка конфига на целевой сервер через плагин `remote-agent` с обязательным ручным подтверждением (Approve Guard).
- 📂 **Ресурсы (MCP Resources)**:
  - `config-studio://projects/tree`: актуальное дерево файлов открытого проекта.
  - `config-studio://servers/status`: список подключенных серверов и их доступность.
- 🔒 **Изоляция и безопасность**:
  - Полный контроль прав: ИИ не может применить изменения без явного одобрения пользователя в интерфейсе Config Studio.

### 10. 🎯 Архитектурный принцип: Строгая ассоциация плагинов (`fileMatches`)
Ядро Config Studio обеспечивает строгую изоляцию элементов управления плагинов в зависимости от открытого файла:
- Каждый плагин декларирует свои маски в `plugin.json`:
  - Имена файлов: `["Makefile", "Dockerfile", "docker-compose.yml", "compose.yaml"]`
  - Расширения: `[".html", ".php", ".yaml", ".json"]`
  - Glob-паттерны: `["*.mk", "*.conf"]`
- Тулбар редактора, пункты контекстного меню и провайдеры структуры отображаются **только** для ассоциированных типов файлов. Никакого визуального мусора при редактировании обычных конфигов!

### 11. ⚡ UX/UI: Панель инструментов быстрого действия (1-Click Action Toolbar)
Оптимизация интерфейса для сокращения количества кликов до минимума (Zero-Friction UX).

#### Ключевой UX-дизайн:
- **Принцип «Primary Action в 1 клик» (Split Action Button)**:
  - Вместо вложенных меню и цепочек кликов:
    - `Makefile`: кнопка `[ ▶ Run: build ]` запускает главную/последнюю цель ровно в **1 клик**. Стрелочка `[ ▾ ]` рядом открывает выпадающий список ТОЛЬКО если нужно переключить цель.
    - `docker-compose.yml`: прямые кнопки `[ 🚀 Up -d ]` и `[ ⏹ Down ]` в 1 клик.
    - `HTML / PHP`: кнопка `[ 🌐 Preview ]` в 1 клик.
  - Последнее запущенное действие запоминается и становится дефолтным для файла.
- **Нулевой визуальный шум (Adaptive Toolbar)**:
  - Панель не занимает драгоценную высоту экрана, если для текущего файла нет активных плагинов.
  - Кнопки компактно размещаются в правой части панели вкладок (Tab Header) либо в тонкой контекстной полосе действий.
- **Нулевые клики через горячие клавиши (Zero-click hotkeys)**:
  - Каждое первичное действие тулбара привязано к шорткату, отображаемому в тултипе (`F5` или `Ctrl+Shift+B` для Make, `Ctrl+Alt+U` для Up, `Ctrl+Shift+P` для Live Preview). Продвинутые пользователи управляют процессами без мыши.
