# Config Studio Roadmap & Planned Plugins 🗺️

План развития экосистемы **Config Studio** и официальных плагинов.

---

## 📋 Запланированные плагины и функции

### 1. 🐳 Плагин: Docker & Compose Manager (`config-studio-docker`)
Полноценное управление контейнерами и сценариями Docker Compose прямо из интерфейса редактора.

#### Ключевой функционал:
- **Контекстные кнопки в панели инструментов** (активируются при открытии `docker-compose.yml`, `compose.yaml`, `Dockerfile`):
  - 🚀 **Compose Up (`-d`)** — фоновый запуск стека сервисов.
  - ⬇️ **Compose Down** — корректная остановка и удаление контейнеров и сетей.
  - 🔄 **Compose Pull & Restart** — обновление образов и перезапуск контейнеров в 1 клик.
  - 📋 **Live Logs Viewer** — стриминг логов сервисов в нижнюю панель (Bottom Panel) в реальном времени с поддержкой паузы и фильтрации.
  - 🔍 **Status & Containers Dashboard** (`docker compose ps` / `docker ps`) — интерактивный список контейнеров со статусами (Up/Exited), портами и кнопками перезапуска каждого сервиса по отдельности.
- **Поддержка синтаксиса и AST**:
  - Сниппеты для директив Compose (`services`, `volumes`, `networks`, `environment`, `healthcheck`, `deploy`).
  - Outline Provider для быстрого перехода к отдельным сервисам в дереве структуры документа.
- **Требуемые разрешения**: `ui.panels`, `terminal.exec`.

### 2. 📡 Плагин: Remote Server Agent — Broadcast & Multicast с функцией Approve
Расширение для плагина [`config-studio-remote-agent`](https://github.com/EdvardBaldanov/config-studio-remote-agent) для кластерного управления.

#### Ключевой функционал:
- **Тегирование и группы серверов**: разделение парка серверов по тегам (`prod`, `staging`, `edge`, `backend`).
- **Синхронная рассылка (Multicast / Broadcast)**: отправка отредактированного конфига сразу на несколько или все подключенные серверы.
- **Интерактивный экран подтверждения (Approve Modal)**:
  - Визуальный просмотр Diff (изменений).
  - Pre-flight детекция дрифта (проверка хешей и предупреждение, если файл на сервере был отредактирован локально).
  - Выборочное включение/исключение серверов чекбоксами.
  - Кнопка **«Approve & Deploy»**.
- **Отказоустойчивость**: автосоздание `.bak` копий на целевых узлах и детальный отчет доставки (Success/Failed).

### 3. 💻 Скрываемая нижняя панель для CLI и инструментов (Collapsible Bottom Dock)
Выделенная нижняя док-панель (Bottom Console / CLI Panel) для размещения встроенных терминалов, потоков вывода команд и консольных инструментов.

#### Ключевой функционал:
- **Универсальный Bottom Dock**:
  - Поддержка переключения видимости через API плагинов: `window.ConfigStudio.toggleBottomPanel({ id, title, render })`.
  - Глобальный хоткей для быстрого сворачивания / разворачивания (по аналогии с VS Code / JetBrains: `Ctrl+\`` или `Ctrl+J`).
  - Кнопка быстрого доступа в панели состояния (Status Bar) или тулбаре редактора с индикатором активных сессий.
- **Интерактивные возможности**:
  - Многовкладочность в нижней панели (например, вкладка `Terminal`, вкладка `Docker Compose Logs`, `Output`).
  - Плавный ресайз высоты (drag-to-resize сплиттером) и пресеты высоты (минимизировано / 240px / 420px / полноэкранный режим).
  - Сохранение состояния (открыта/закрыта, высота) в пользовательских настройках (`settings.json`).
- **Целевые сценарии применения**:
  - 🖥️ **CLI / Terminal плагин** (`config-studio-terminal` / `config-studio-cli` на базе xterm.js): доступ к локальному шеллу (PowerShell, Bash, zsh) или удаленной SSH-консоли серверов.
  - 🐳 **Стриминг логов**: вывод stdout/stderr контейнеров `docker compose logs -f`.
  - ⚡ **Task Runner / Build Output**: отображение вывода линтеров, сборщиков и скриптов валидации.
- **Требуемые разрешения**: `ui.panels`, `terminal.exec`.

### 4. 📦 Динамический каталог плагинов и доверенные репозитории (Dynamic Plugin Registry & Discovery)
Переход от жестко зашитого списка плагинов в коде к динамическому обнаружению и поддержке доверенных источников (Trusted Registries).

#### Ключевой функционал:
- **Динамическое обнаружение (Discovery по маске GitHub)**:
  - Автоматический опрос GitHub API для поиска репозиториев организации или пользователя (по маске `config-studio-*` или топику `config-studio-plugin`).
  - При появлении нового репозитория с валидным манифестом `plugin.json` (например, `config-studio-docker`), плагин автоматически появляется в каталоге без необходимости перевыпускать бинарник редактора.
- **Центральный индекс каталога (`registry.json`)**:
  - Хранение актуального индекса в репозитории документации [`config-studio-plugin-docs`](https://github.com/EdvardBaldanov/config-studio-plugin-docs).
  - Загрузка в один быстрый HTTP-запрос при открытии вкладки настроек (без ограничений на GitHub API rate limit) с локальным кэшированием и оффлайн-фоллбэком.
- **Пользовательские доверенные источники (Custom Trusted Registries)**:
  - Возможность в настройках редактора (`Настройки` -> `Плагины` -> `Источники`) указать собственные доверенные репозитории или организации (например, корпоративный GitHub / GitLab).
  - Поддержка закрытых корпоративных плагинов и самописных расширений.
- **Проверка безопасности и подписей**:
  - Предупреждения при установке плагинов из сторонних непроверенных источников.
  - Проверка совместимости требуемой версии редактора (`minAppVersion`).
